# 신규 PDF 문서 이름의 파일명 기본값

사용자가 요청한 PDF 파일명 기준 자동 저장을 신규 색인의 기본 동작으로 적용한다.

- `document_id` 미지정 시 기존처럼 `Path(path).stem`을 사용한다.
- `doc_name` 미지정 시 내부 PDF 제목 대신 `Path(pdf_path).stem`을 사용한다. 괄호·다운로드 번호·중간 마침표를 보존하고 마지막 확장자만 제거한다.
- 공통 PDF 파이프라인에서 결정해 MCP 백그라운드 색인·CLI 동기 색인과 재파싱에 적용한다.
- 명시적 문서 ID/표시명 인자는 기존 API와 재색인 호환을 위해 유지한다. MCP 문서에는 사용자가 별도 이름을 요청한 경우에만 지정하도록 안내한다.
- PDF 내부 제목·본문은 수정하지 않고 회계연도 추출 규칙도 유지한다.
- 파싱 폴더, 매니페스트, 저장 청크, 벡터 payload, 검색 결과/문서 목록의 이름 일치를 fake 파서·fake 임베딩·임시 Qdrant로 검증한다.
- 운영 데이터 재색인이나 모델 다운로드는 수행하지 않는다.
