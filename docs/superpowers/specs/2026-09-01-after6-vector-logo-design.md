# AFTER6 흰색 벡터 로고 설계

## 목표

사용자가 선택한 `After6` 로고를 자동 이미지 추적 없이 도형으로 다시 구성한다. 결과물은 확대해도 깨지지 않고 글꼴 설치 여부에 영향을 받지 않는 순수 SVG 파일이어야 한다.

## 최종 산출물

- 파일: `output/after6-logo-white.svg`
- 표기: A 엠블럼과 소문자 `fter`, 숫자 `6`을 결합한 `After6`
- 색상: 모든 로고 요소를 단색 흰색(`#FFFFFF`)으로 통일
- 배경: 완전 투명하며 배경 사각형을 넣지 않음
- 형식: `<path>`, `<polygon>`, `<circle>` 등 SVG 벡터 요소만 사용
- 금지: `<image>`, `<text>`, 외부 글꼴, 래스터 이미지, 그라데이션, 그림자, 금속 질감

## 시각 구성

1. 왼쪽 A 엠블럼은 기울어진 두꺼운 A와 부분 원형 테두리, 오른쪽을 향하는 가로획으로 구성한다.
2. A 엠블럼 자체가 첫 글자이므로 오른쪽에는 `fter6`만 배치한다.
3. `fter`는 사용자가 선택한 시안처럼 굵고 현대적인 소문자 형태로 직접 그린다.
4. 숫자 `6`은 `fter`보다 시각적으로 과도하게 커 보이지 않도록 광학 크기와 간격을 조정한다.
5. 전체 로고는 가로형으로 구성하고 좌우·상하에 충분한 투명 여백을 둔다.

## 구현 구조

- 루트 `<svg>`에 고정 `viewBox`를 두어 모든 크기에서 동일한 비율을 유지한다.
- `aria-label="After6"`와 `<title>`을 넣어 접근 가능한 이름을 제공한다.
- A 엠블럼과 `fter6`를 각각 `<g>`로 묶어 후속 위치·크기 조정이 가능하게 한다.
- 모든 도형은 흰색 채움으로 통일하고 배경 요소는 만들지 않는다.

## 품질 기준

- SVG가 XML로 정상 파싱된다.
- 래스터 이미지와 글꼴 의존 요소가 없다.
- 확대 시 선과 곡선이 깨지지 않는다.
- 어두운 배경에 렌더했을 때 `After6`로 즉시 읽힌다.
- A 엠블럼과 `fter6` 사이 간격, 기준선, 숫자 6의 크기가 시각적으로 균형을 이룬다.
- SVG 바깥 영역과 도형 사이 영역은 실제 투명이다.

## 검증 방법

1. XML 파서로 SVG 문법을 검사한다.
2. `<image>`와 `<text>` 요소가 없는지 확인한다.
3. SVG를 PNG로 렌더해 투명 배경과 흰색 채움을 확인한다.
4. 검은 배경 위에 합성한 미리보기로 원본 시안의 인상과 글자 판독성을 비교한다.

## 범위

이번 작업은 흰색·투명 배경 SVG 한 개 제작까지로 제한한다. 검은색 버전, 컬러 버전, PDF·EPS 변환 및 상표 등록용 정밀 도면은 별도 요청이 있을 때 추가한다.
