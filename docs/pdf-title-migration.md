# PDF 파일명과 문서 이름 맞추기

`scripts/rename_documents_to_pdf_titles.py`는 원본 PDF 파일명에서 `.pdf`를 뺀 값을
문서 ID와 표시 이름으로 사용하도록 기존 자료를 이관하는 관리 도구다.
다운로드 번호 `(1)`·`(3)`도 파일명 일부로 유지한다. 원문 제목·본문은 바꾸지 않는다.

같은 내용의 PDF가 프로젝트 `pdf` 폴더에 있으면 SHA-256을 대조해 그 파일을 우선한다.
원본이 없으면 매니페스트에 기록된 파일명을 사용하며 재파싱하지 않는다.
이미 벡터 컬렉션이 없는 과거 파싱 자료는 다시 색인하지 않는다.

## 실행

모든 RAG MCP의 색인 작업이 끝난 뒤 MCP 서버를 중지한다. Qdrant HTTP 서버는 유지한다.
같은 데이터 폴더의 쓰기 잠금도 획득하지만, 업데이트 이전 MCP나 관리 스크립트가
잠금을 따르지 않을 수 있으므로 서버 중지가 필요하다.

```powershell
$env:PYTHONPATH='src'
.\.venv\Scripts\python.exe scripts/rename_documents_to_pdf_titles.py `
  --data-dir .\data --pdf-dir .\pdf --url http://127.0.0.1:6333 `
  --backup-dir .\data\backups\pdf-title-migration
```

기본은 읽기 전용 계획 출력이다. 계획의 이름·경로·수량·목적지 충돌을 확인한 뒤
같은 명령에 `--apply`를 추가한다. 백업 디렉터리는 아직 존재하지 않는 경로여야 한다.

## 변경과 검증

- 파싱 폴더, JSON·Markdown·이미지 폴더와 내부 리소스 경로, 청크 ID·문서명·원본 경로,
  매니페스트, 벡터 DB의 문서 이름·포인트 ID를 함께 바꾼다.
- 벡터는 기존 dense/sparse 값을 복사하며 임베딩 모델을 실행하지 않는다.
  Qdrant COSINE이 float32를 다시 정규화하는 반올림 차이만 허용한다
  (dense 원소별 절대오차 `1e-7` 이하, sparse·payload는 완전 일치).
- Qdrant 컬렉션명은 기존 `rag_<모델>_<문서 이름>_<구분값>` 규칙을 유지한다.
- 원래 매니페스트·청크, 컬렉션 설정·전체 벡터와 payload를 백업한 뒤 변경한다.
  이름이 바뀐 파싱 폴더 원본도 백업에 보존한다. 새 데이터 검증이 끝나야 이전 컬렉션을 지운다.
- 예외 발생 시 파일 복구를 먼저 수행하고 DB 복구도 시도한다. DB가 계속 응답하지 않으면
  백업 위치와 남은 복구 오류를 명시한다. 강제 종료 후에는 백업을 바탕으로 복구해야 한다.

적용 후 MCP를 다시 시작한다. `list_documents`, sparse 검색, 페이지 이미지와 문서별
청크 수를 확인한다. 이전 문서 ID 대신 변경된 문서 ID를 사용한다.
